# FUTEBOL DELAS ⚽💗
Site informativo para valorizar e divulgar o futebol feminino.

## Arquivos
- `index.html`: conteúdo e estrutura.
- `style.css`: visual, cores, layout responsivo.
- `script.js`: menu interativo para celular.

## Publicar no GitHub Pages
1. Abra seu repositório no GitHub.
2. Envie estes arquivos substituindo os antigos (index.html, style.css e script.js).
3. Faça Commit changes.
4. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
5. Aguarde alguns minutos para a publicação atualizar.

As imagens externas estão ligadas a páginas do Wikimedia Commons; confira os créditos/licenças pelos links indicados no site. Algumas atletas têm link para galerias porque não foi possível confirmar uma fotografia específica para inclusão direta.
