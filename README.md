# Futebol Delas

Site informativo para valorização e divulgação do futebol feminino (TCC).
Feito com HTML, CSS e JavaScript puro.

**Slogan:** Mais que um esporte, uma conquista de todas!

## Funcionalidades
- Linha do tempo interativa
- Galeria de 7 jogadoras com filtro, cartões com foto e janela "Conheça a história"
- Categorias de base (Sub-11 a Sub-20)
- "Você sabia?" com curiosidades aleatórias
- Quiz com 8 perguntas e pontuação
- Mensagens de incentivo

## Como editar o conteúdo
Fotos: coloque em `imagens/` (veja `imagens/LEIA-ME.txt`).

Todo o texto das jogadoras, linha do tempo, curiosidades, frases e quiz está no início do arquivo `script.js`.

## Como publicar no GitHub Pages
1. Crie um repositório no GitHub e envie estes arquivos.
2. Vá em **Settings > Pages**.
3. Em *Branch*, escolha `main` e a pasta `/ (root)`. Salve.
4. Em alguns minutos o site estará em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
